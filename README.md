# Cooperadora EP7 - Sistema de Gestión de Pagos

Sistema web completo para la gestión de pagos, socios y bonos de la **Cooperadora Escolar de la Escuela N° 7 Juan Bautista Alberdi**, San Miguel, Buenos Aires.

## 🌐 Página en vivo

Una vez subido a GitHub Pages, tu sistema estará online en:

```
https://TU-USUARIO.github.io/cooperadora-ep7/
```

## 📂 Archivos principales

| Archivo | Función |
|---------|---------|
| `index.html` | Página pública de la cooperadora (inicio, novedades, contacto) |
| `pagos.html` | Sistema de pagos, gestión de socios, admin panel, exportación CSV |
| `libro-socios.html` | Gestor digital del libro de socios con exportación a Excel |

## 🚀 Cómo usar (sin programación)

1. **Los usuarios** (padres/familias) entran a la página y generan su pago.
2. **Los administradores** acceden con la contraseña: `coop2025`.
3. **Los datos** se guardan en el navegador de cada dispositivo. Para compartir entre dispositivos, configurar Google Sheets (ver guía abajo).

## 📖 Guías incluidas

- `GUÍA_GITHUB_PAGES.md` - Cómo subir el sistema a GitHub Pages (gratis, online)
- `INSTRUCCIONES_GOOGLE_SHEETS.md` - Cómo conectar con Google Sheets (nube)
